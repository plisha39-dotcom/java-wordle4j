# Wordle4j

Консольная версия Wordle на русском языке. Нужно угадать слово из пяти букв за шесть попыток, используя подсказки о совпавших буквах.

Учебный проект в рамках курса Java-разработки Яндекс Практикума.

## Возможности

- Случайный выбор слова из словаря.
- Проверка длины, кириллицы и наличия слова в словаре.
- Подсказки с корректным учётом повторяющихся букв.
- История попыток в текущей игре.
- Подбор возможного слова с учётом предыдущих ходов.
- Нормализация ввода: удаление пробелов по краям, приведение к нижнему регистру и замена «ё» на «е».
- Запись событий и ошибок в `wordle.log`.

## Технологии

Java 21 · Collections · файловый ввод-вывод · обработка исключений · JUnit 5

## Правила и управление

| Ввод или символ | Значение |
| --- | --- |
| Слово из пяти букв | Сделать попытку |
| Enter без текста | Получить возможный вариант |
| `0` | Завершить игру |
| `+` | Буква находится на своём месте |
| `^` | Буква есть в слове, но находится в другом месте |
| `-` | Для этой буквы не осталось совпадений в загаданном слове |

При повторяющихся буквах сначала учитываются точные совпадения, затем остальные буквы сопоставляются с оставшимся количеством букв в ответе. Некорректный ввод не расходует попытку.

## Запуск

Нужны JDK 21 и IntelliJ IDEA.

1. Склонировать репозиторий:

   ```bash
   git clone https://github.com/plisha39-dotcom/java-wordle4j.git
   ```

2. Открыть проект в IntelliJ IDEA и выбрать JDK 21.
3. Установить рабочую папку запуска в корень репозитория: там находится `words_ru.txt`.
4. Запустить `main` в классе `ru.yandex.practicum.Wordle`.

Игра читает словарь из `words_ru.txt`. Файл `wordle.log` создаётся в рабочей папке и перезаписывается при новом запуске.

## Устройство проекта

- `Wordle` — консольный ввод, вывод и обработка команд.
- `WordleGame` — состояние игры, попытки и подбор слова.
- `WordleDictionary` — словарь, нормализация и сравнение слов.
- `WordleDictionaryLoader` — загрузка словаря из файла.
- `exceptions` — ошибки загрузки и игровые исключения.

## Тестирование

В IntelliJ IDEA запустить тесты из папки `test`. Для тестов используется JUnit 5; JAR-зависимости проекта подключаются из папки `lib`.

Проверяются:

- точные совпадения, перестановки и повторяющиеся буквы;
- нормализация и некорректный ввод;
- ограничения числа попыток и завершение игры;
- подбор слова по истории ходов;
- загрузка словаря и обработка ошибок.

## Ограничения

Игра работает в консоли с русскими словами из пяти букв. Прогресс текущей игры не восстанавливается после закрытия приложения. Maven и Gradle не настроены.

## Учебный фокус

Алгоритм сравнения слов в два прохода, подсчёт букв через Map, разделение игровой логики и консольного интерфейса, работа с файлами и тестирование граничных случаев.
